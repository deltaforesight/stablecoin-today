# Stablecoin Today

Daily English podcast on stablecoin news, produced by DeltaForesight.

- Feed: https://podcast.deltaforesight.com/feed.xml
- Site and feed are served by GitHub Pages from `docs/`.
- Episode audio is attached to GitHub Releases (`ep-YYYY-MM-DD`).
- `tools/build_feed.py` regenerates `docs/feed.xml` from `tools/show.json` and `tools/episodes.json`.

Episodes are generated with AI from published news reports and are not investment advice.
